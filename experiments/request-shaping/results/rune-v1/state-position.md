# Study 3 results: position in state (fireworks-systemone)

Generated by `state-position report` from saved receipts. Fireworks System One `accounts/fireworks/routers/rune`; every judged BM25 candidate of 20 seeded TREC DL queries is a target. Each target is placed among 9 or 39 fixed off-topic filler passages (drawn from other queries' candidates), at the start, 25%, middle, 75%, or end of the `passages` array; only the target's position changes. **Pointed** asks about the target by its opaque id. **Needle** asks whether any passage is useful, so a relevant target must be found without a pointer. Unless named `qfirst`, the question field follows the passages. AUC separates grade ≥ 2 targets from the rest. Intervals are 95% query-cluster bootstrap intervals (2,000 replicates) stratified by year.

**Provider:** Fireworks System One decisions API, model `accounts/fireworks/routers/rune`, body preparation `v1`. Every request is the Jev request body of the same job (`payload_sha256` matches the Jev plan) with only `model` replaced (`sent_request_sha256` in each receipt); state and questions are byte-identical and nothing is translated. No `reasoning_effort`, images or options are sent.

**Execution:** four workers; transport/408/429/5xx retries honor Retry-After, bounded at 30 attempts in the completed runs.

**Prices.** USD figures are accounting estimates at [Rune](https://fireworks.ai/models/fireworks/rune)'s dated rate: $0.042 per million input tokens (cached or not); output is free and no output tokens were reported. They are not invoices. The observed packed-length limit was 16,384 tokens.

**Jev comparison:** `jev-1.13.0` columns use the same plan and request bodies in `results/state-position-v1`.

**Response model echo:** `accounts/fireworks/routers/rune` (32454 requests).

**Noise floor:** this study has no retest arm. Read System One differences against the System One retest noise measured in the System One runs of Studies 1 and 2 (`state-packing` `retest`, `question-fanout` `retest-useful`), not against Jev's.
