# OpenAI Decisions request-shaping aggregates

[`summary.json`](summary.json) holds the source-free numbers behind the [Decisions re-run section](../../README.md#openai-decisions-re-run-2026-10-06). It was generated by `publication/decisions-aggregates.py` in the private repository and lists the private source files it read with their SHA-256 (`sources`): each study's generated Decisions report, manifest and resources file. It contains numbers and machine identifiers only (arm names); no passage or query text, request bodies, receipts or raw provider responses.

Under `data.studies.<study>` (`state-packing`, `question-fanout`, `state-position`):

- `resources`: per arm, requests, scored decisions, reported input tokens (total and per decision), list-price USD at $0.10 per million input tokens, refused questions, request latency p50/p95 (HTTP round trip) and retried requests.
- `totals`: the same summed over the study.
- `report_tables`: every table of the generated Decisions report, keyed by section heading, one object per row with the report's column names. These include the frozen Jev columns the report places beside each Decisions estimate, the noise floor, refusal counts, score granularity and the same-request Decisions-versus-Jev comparison.

`data.pending_studies` is empty: all three studies completed. The human-readable reports are [state packing](../state-packing-openai-decisions-v1/REPORT.md), [question fan-out](../question-fanout-openai-decisions-v1/REPORT.md) and [position in state](../state-position-openai-decisions-v1/REPORT.md); the frozen Jev reports are [state packing](../state-packing-v1/REPORT.md), [question fan-out](../question-fanout-v1/REPORT.md) and [position in state](../state-position-v1/REPORT.md).

Costs are list-price estimates from reported usage, not invoices. Intervals are 95% query-cluster bootstrap intervals stratified by year.
