# Study 3 results: position in state (openai-decisions)

Generated by `state-position report` from saved receipts. OpenAI Decisions `gpt-6-luna`; every judged BM25 candidate of 20 seeded TREC DL queries is a target. Each target is placed among 9 or 39 fixed off-topic filler passages (drawn from other queries' candidates), at the start, 25%, middle, 75%, or end of the `passages` array; only the target's position changes. **Pointed** asks about the target by its opaque id. **Needle** asks whether any passage is useful, so a relevant target must be found without a pointer. Unless named `qfirst`, the question field follows the passages. AUC separates grade ≥ 2 targets from the rest. Intervals are 95% query-cluster bootstrap intervals (2,000 replicates) stratified by year.

**Provider:** OpenAI Decisions API, model `gpt-6-luna` (normalized label `openai-decisions/gpt-6-luna`), endpoint `https://openai.int.exe.xyz/v1/decisions`, wire format `guide-2026-10-06` (the documented format of the public-beta guide, 2026-10-06; see `../openai-decisions-adapter/decisions/wire.go`). Every request is the frozen Jev request body of the same job (`payload_sha256` matches the Jev plan), translated by the shared adapter: the Jev state becomes the text `input`, and each Noul question becomes a `predicate` question with the same name and instructions.

**Probabilities:** Decisions predicates return the probability that the condition is true directly, so p is the API's own `probability`, with no derivation or approximation. Whether those values are rounded or tie is measured in *Score granularity* below, not assumed.

**Prices:** USD figures use the published list price, $0.10 per million input tokens; output tokens are not billed. They are list-price estimates, not invoices; regional or long-context multipliers, if any applied, are not modeled.

**Execution (first invocation):** 16 workers, client limit 3000 requests/minute, HTTP timeout 300s; resumed invocations may differ (see `run.log`).

**Frozen Jev comparison:** `jev-1.13.0` columns replay the frozen 2026-09-25 run in `results/state-position-v1` (same plan, same request bodies).

**Served model labels:** `openai-decisions/gpt-6-luna` (32454 requests). More than one label means the snapshot changed during the run.

**Refusals:** a `refusal` answer is a non-answer. It is recorded in the receipt (`refused`), never retried, and never given a probability. Every metric excludes refused decisions, and each affected row or figure is tagged `[N refused, excluded]` with the count from the arms it is computed over. Paired comparisons (Δp, Δ AUC, nDCG differences) also drop pairs whose reference decision was refused; the reference row carries that count. nDCG@10 drops a query from a condition when any of its candidates was refused, because a ranking with a missing candidate is not comparable. **No question was refused.**

**Noise floor:** this study has no retest arm. Read Decisions differences against the Decisions retest noise measured in the Decisions runs of Studies 1 and 2 (`state-packing` `retest`, `question-fanout` `retest-useful`), not against Jev's.
