# OpenAI Decisions Claude RAG aggregates

[`summary.json`](summary.json) holds the source-free numbers behind the [Decisions re-run section](../../README.md#openai-decisions-re-run-2026-10-06). It was generated by `publication/decisions-aggregates.py` in the private repository and lists every private source file it read with its SHA-256 (`sources`). It contains numbers and machine identifiers only; no EnronQA questions, reference answers, chunks, generated answers, receipts or raw provider responses.

Under `data.modes.threshold` and `data.modes.categorical`:

- `same_judge_correct`: answers accepted by `deepseek-v4p1-flash` for the unfiltered, frozen Jev and Decisions arms. Unfiltered and Jev verdicts come from a re-judge of the frozen answers with the frozen judge prompt (only those two arms were read); Decisions verdicts come from its own run with the same judge model.
- `same_judge_discordant` and `same_judge_paired_intervals`: questions answered correctly by only one of two arms, and paired differences with 95% cluster-bootstrap intervals by source document (descriptive).
- `chunks`, `per_result_on_identical_inputs`, `returned_context_proxy_tokens`: chunks kept and returned, chunk-level agreement with the frozen Jev filter (and, for categorical mode, the category confusion matrix), and context size.
- `filter_stage`, `refused_results`, `answer_stage_latency_s`, `estimated_api_equivalent_usd`, `source_coverage`: Decisions requests, tokens and cost, refusals (none), answer-stage timings for the Decisions arm and the frozen Jev arm, API-equivalent pipeline cost estimates, and initial-search source coverage.

`data.rescore_judge` reports Decisions as an answer judge on the frozen answers: acceptances, agreement with the frozen DeepSeek and Jev rescoring verdicts, requests, tokens, cost and latency.

The Decisions arms' Claude answers came through Claude Code on a Team subscription; the frozen arms used Claude Code Max. Claude costs are API-equivalent list estimates, not subscription charges.
