# OpenAI Decisions reranking aggregates

## TL;DR

SubQ produced the best relevance ranking in this 97-query TREC DL comparison: its expected-grade score reached 0.7206 nDCG@10, ahead of Decisions at 0.7006, Qwen3 Reranker 8B at 0.6994, and Jev at 0.6917. Against Jev, SubQ's expected-grade gain was +0.0289 with a 95% interval of [+0.0124, +0.0470]; its +0.0212 interval against Qwen narrowly included zero. Expected grade was the strongest frozen scoring formulation for every decision-model provider, while probability was weakest. Decisions roughly matched Qwen and Jev on the primary arms, and 23 refusals hurt one exploratory ordinal prompt. SubQ also had the lowest estimated list cost for its three primary arms, at $0.46 total versus $0.62 for Jev, $1.28 for Decisions, and $0.33 for Qwen. The benchmark is small, public, and potentially present in model training; prompt variants were inspected on the same queries, so the exploratory best-prompt results are not held-out validation.

[`summary.json`](summary.json) holds the source-free numbers behind the [provider comparison](../../README.md#provider-comparison). It was generated by `publication/decisions-aggregates.py` in the private repository and lists every private source file it read with its SHA-256 (`sources`). It contains numbers and machine identifiers only (method names, TREC query ids); no passage or query text, receipts or raw provider responses.

Fields under `data`:

- `main`: the three main arms. `aggregates` holds nDCG@10, MRR@10, recall@10/100 and query wall-time p50/p95 per `method/stratum` (`all`, `dl19`, `dl20`); `paired_vs_qwen` and `paired_vs_frozen_jev` hold paired differences in nDCG@10 with 95% bootstrap bounds (queries resampled within year, 10,000 replicates, seed 20260918); `resources` holds requests, failures, tokens and list-price USD.
- `prompt_study`: the same metrics for all twelve Decisions and Jev arms, Qwen, BM25 and the label oracle. Provider-specific execution settings make cross-provider latency descriptive rather than controlled.
- `decisions_diagnostics`: per Decisions arm, requests, failed (retried) attempts, refused requests and questions, BM25-fallback jobs, request latency p50/p95 (HTTP round trip) and input tokens per request.
- `refusal_sensitivity_ordinal_statement`: the 13 TREC query ids whose ordinal-statement job fell back to BM25 after refusals, and mean nDCG@10 plus paired differences over the remaining 84 queries. This sensitivity was computed for this release from the per-query metrics; it is not part of the frozen protocol.
- `totals`: Decisions requests, failed attempts, refused questions, fallback jobs and list-price USD across all Decisions arms.

Costs are list-price estimates at $0.10 per million input tokens from reported usage, not invoices. Query wall times include client pacing (3,000 requests per minute), so they describe this deployment, not model speed.
