# OpenAI Decisions reranking aggregates

[`summary.json`](summary.json) holds the source-free numbers behind the [Decisions re-run section](../../README.md#openai-decisions-re-run-2026-10-06). It was generated by `publication/decisions-aggregates.py` in the private repository and lists every private source file it read with its SHA-256 (`sources`). It contains numbers and machine identifiers only (method names, TREC query ids); no passage or query text, receipts or raw provider responses.

Fields under `data`:

- `main`: the three main arms. `aggregates` holds nDCG@10, MRR@10, recall@10/100 and query wall-time p50/p95 per `method/stratum` (`all`, `dl19`, `dl20`); `paired_vs_qwen` and `paired_vs_frozen_jev` hold paired differences in nDCG@10 with 95% bootstrap bounds (queries resampled within year, 10,000 replicates, seed 20260918); `resources` holds requests, failures, tokens and list-price USD.
- `prompt_study`: the same for all twelve Decisions arms beside the twelve frozen Jev arms, Qwen, BM25 and the label oracle. Rows not starting with `decisions-` are frozen 2026-09-18 results, imported unchanged; their costs and timings are historical.
- `decisions_diagnostics`: per Decisions arm, requests, failed (retried) attempts, refused requests and questions, BM25-fallback jobs, request latency p50/p95 (HTTP round trip) and input tokens per request.
- `refusal_sensitivity_ordinal_statement`: the 13 TREC query ids whose ordinal-statement job fell back to BM25 after refusals, and mean nDCG@10 plus paired differences over the remaining 84 queries. This sensitivity was computed for this release from the per-query metrics; it is not part of the frozen protocol.
- `totals`: Decisions requests, failed attempts, refused questions, fallback jobs and list-price USD across all Decisions arms.

Costs are list-price estimates at $0.10 per million input tokens from reported usage, not invoices. Query wall times include client pacing (3,000 requests per minute), so they describe this deployment, not model speed.
